# Twitch Maginify

Rozszerzenie do Chrome: zaznacz fragment streama na Twitchu (np. kamerkę) i pokaż go powiększonego jako okienko na obrazie.

## Instalacja

1. Pobierz i rozpakuj repozytorium.
2. Wejdź na `chrome://extensions` i włącz **Tryb dewelopera**.
3. Kliknij **Załaduj rozpakowane** i wskaż folder z `manifest.json`.

## Użycie

- **Lupa** obok przycisku „Klip”: zaznacz obszar myszą.
- **Przeciąganie** przesuwa okienko, **kółko myszy** zmienia jego rozmiar.
- **Esc** albo **✕** wyłącza powiększenie.
